Built-in IDE

A GPU code editor that lives inside your terminal.

Ocean ships a native, modeless code editor rendered directly on its instanced OpenGL pipeline — no TUI abstractions, no external window, no Electron. Edit files at terminal speed, split them next to your shell, and keep full Myanmar/Burmese shaping while you type.

Overview

The editor is part of the same binary as the terminal. It reuses Ocean's OpenGL renderer, font system, theme palette, and event loop, so switching between a shell and a source file is instant — no new process, no second window, and no separate configuration.

  • Native GPU pipeline. Cells, glyphs, gutters, tabs, popups, and squiggles are drawn through Ocean's instanced glow/glutin renderer.
  • Rope-backed buffers. ropey keeps edits at O(log N), so multi-megabyte files stay responsive, with a transaction-based undo/redo stack that restores cursor positions.
  • Modeless editing. Familiar developer bindings — Ctrl+S, Ctrl+P, Ctrl+F, Ctrl+Z — with no modal state to think about.
  • Cluster-aware text. Cursor movement, selection, and deletion operate on shaped grapheme clusters, which keeps Burmese syllables intact.
  • Built-in tooling. File explorer, fuzzy file/command palette, find bar, LSP completion and hover, diagnostics, and Extism plugins.
Tip: The editor follows the active Ocean theme and font settings. Switch themes live with Ctrl+Shift+P → Switch Theme and the editor recolors immediately.

Launching the editor

There are two entry paths: launch it directly as an editor, or toggle it on top of a running terminal session.

Ctrl+\Toggle Split mode (Mode B): editor on top, terminal on the bottom.
Context MenuCtrl+Shift+P → Toggle Code Editor (mnemonic i).
Launch examples 
# Open a file directly
ocean edit src/main.rs

# Open a folder as the workspace (enables Ctrl+P file finder and Ctrl+B explorer)
ocean edit .

# Standalone launcher installed by the .deb / .rpm packages
edit src/main.rs

# Start a shell in the parent terminal tab while editing (Mode B)
ocean edit .
When Ocean starts in editor mode, typing ocean edit or edit with no argument opens the current working directory as the workspace.

Motions and operators

  • h j k l and arrows move the cursor; counts work as expected (3j, 5l).
  • w b e move by word; 0 ^ $ target line bounds; gg and G jump to the first/last line.
  • d, y, and c accept motions: dd, dw, d$, dj, dk, cw.
  • x, X, p, P, J, r, and ~ handle character edits, paste, join, replace, and case toggling.
  • u and Ctrl+r undo and redo; Visual d/y/c operate on the selection.
  • Deletion and cursor motion stay grapheme-cluster aware, so x removes a whole Myanmar syllable.
The editor status strip shows the current mode, pending count/operator, command line, and any Ex error message. In Normal/Visual mode every key is consumed by the editor so it never reaches the terminal.

Interface

The editor uses a VSCode-inspired layout with a single set of chrome elements that stay consistent across Split and Pure Editor modes.

  • Document tabs are always visible, with an active accent, unsaved dirty dot, per-tab close button, and a + button for a new document.
  • Breadcrumbs below the tabs show the active file path relative to the workspace root.
  • Activity bar on the left switches between Explorer and Problems; the magnifier opens the command palette.
  • Problems panel lists diagnostics across open documents; click an entry to open the file and jump to the line.
  • Status bar shows the mode, file, error/warning counts, cursor position, language, and LSP state.
  • Code surface adds a full-width current-line highlight, indent guides, matching-bracket highlights, and cluster-aware selection.
  • Command palette dims the editor behind a wider modal panel.
  • Pure Editor hides the terminal tab bar and global shortcut bar, leaving one top tab row and one bottom status bar.

File explorer

Toggle the workspace tree with Ctrl+B. The sidebar is backed by the folder you opened with ocean edit <dir> (or the inherited shell working directory).

  • Click a directory to expand or collapse it; click a file to open it in a new tab.
  • Click the header to rescan the workspace after files change on disk.
  • Drag the right edge of the sidebar to resize it. The default width is 210 px with an 80 px minimum.
  • Mouse wheel scrolls the tree independently of the editor buffer.
  • Noisy directories — .git, target, node_modules, .cache, and .DS_Store — are skipped automatically.

Command palette & file finder

Press Ctrl+P for a single fuzzy entry point powered by nucleo-matcher. Typing filters both built-in commands and workspace files, ranked by match quality.

  • File search walks the workspace up to eight levels deep, respecting .gitignore and hidden-file rules.
  • Built-in commands include Save, New Document, Close Document, Find, Toggle Explorer, Toggle Split, Pure Editor, Pure Terminal, Trigger Autocompletion, and plugin reload.
  • Plugin commands registered through the WASM host appear alongside built-ins.
  • Up/Down move the selection, Enter executes, Backspace edits the query, and Esc dismisses.

Language server behavior

  • One server per language. A mixed workspace can run Rust, TypeScript, HTML, and CSS servers at the same time; each keeps its own project root and diagnostics.
  • Servers start automatically when a supported file is opened and communicate over stdio with JSON-RPC in background threads, so typing never blocks.
  • The client completes the LSP initialize handshake before sending document notifications, and answers server requests such as client/registerCapability and workspace/configuration.
  • Document open, change, save, and close notifications use monotonic revisions.
  • Completions and hover results are delivered asynchronously and matched to the file that requested them, so stale popups no longer appear.
  • Positions are converted between UTF-16 and shaped grapheme clusters, keeping diagnostics and hover correct for Myanmar and other non-ASCII text.
  • Errors and warnings render as colored gutter markers, Problems panel entries, and underline squiggles.
  • If no server binary is installed, editing still works: the status bar shows LSP: <server> not found and completion falls back to words already present in the buffer. Install the server and use the palette action LSP: Restart Language Server.
Install examples: rustup component add rust-analyzer, go install golang.org/x/tools/gopls@latest, npm i -g vscode-langservers-extracted yaml-language-server, npm i -g vtsls, cargo install taplo-cli marksman, npm i -g bash-language-server, plus your distribution's clangd and python-lsp-server packages.

Myanmar editing

The editor does not treat text as isolated codepoints. Lines are segmented with unicode-segmentation and shaped with rustybuzz, so the cursor, selection, and deletion all respect complete Burmese grapheme clusters.

Kinzi + Tall AA
မင်္ဂလာပါ — မြန်မာဘာသာစကား
Stacked Consonants & Medials
ပြည်ထောင်စု • ဗုဒ္ဓဘာသာ • ဣန္ဒြေ • တက္ကသိုလ်
Pre-base E + Medial Ra
ကြွေးမြီ • ကြေ • မြေ
  • Cluster cursor movement. Arrow keys step over a whole syllable instead of landing between a base consonant and its vowel or virama.
  • Atomic deletion. Backspace and Delete remove composite clusters without leaving orphaned diacritics or dotted circles.
  • UTN #11 normalization. Out-of-order typing such as ကုိ is normalized to ကို, and ကေြ to ကြေ.
  • IME commits reach the document. Text composed by IBus, Fcitx, or Keyman is inserted at the editor caret instead of being sent to the shell.
  • Visible preedit. Wayland (zwp_text_input_v3) and X11 (XIM) composition is rendered as a shaped pill at the editor cursor.
  • Space and dead keys work. Space inserts a document space, and event.text fallbacks cover compose sequences and non-IME Burmese layouts.
  • Vim-aware IME. With editor-keymap = vim, IME input is enabled only in Insert mode; Normal and Visual mode keys never leak into the terminal.
  • Zawgyi-One display. Ctrl+Shift+M toggles legacy log/file display without changing the underlying Unicode text.

WASM plugins

Ocean embeds extism to run sandboxed WebAssembly plugins built for wasm32-wasip1. Drop .wasm files into ~/.config/ocean/plugins/; each file stem becomes the plugin name.

Host functionSignaturePurpose
ocean_get_buffer_slice(offset: i64, len: i64) -> StringRead a byte range from the active buffer
ocean_insert_text(offset: i64, text: String)Queue text insertion at a character offset
ocean_register_command(name: String, callback: String)Expose a command in the Ctrl+P palette
ocean_add_status_item(text: String)Add a persistent label to the editor status bar
  • Pending insertions are applied safely on the main thread and clamped to the buffer length.
  • Registered commands run their callback function when selected from the command palette.
  • Status items appear next to the LSP state in the editor status bar.
  • Reload plugins without restarting via the palette action Plugins: Reload WASM Plugins.

Customization

Workspace toggles are ordinary Ghostty-style keybinds, so they can be rebound in ~/.config/ocean/config. The editor itself uses your active theme palette and terminal font.

~/.config/ocean/config 
# Workspace toggles
keybind = ctrl+shift+i=toggle_editor
keybind = ctrl+backslash=toggle_split_mode

# Editor keymap: modeless (default) or vim
editor-keymap = modeless

# Theme and typography are shared with the terminal
theme                = ocean-dark
font-family          = Cascadia Code NF
font-family-myanmar = Padauk
font-size            = 13.5
  • Changes hot-reload when you save the config, or immediately with Ctrl+Shift+,.
  • Validate syntax anytime with ocean +validate-config, or inspect resolved values with ocean +show-config.
  • Per-document state — cursor, scroll position, language, and undo history — is kept while the tab stays open.
