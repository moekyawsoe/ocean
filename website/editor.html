Code editor

A clean code editor, built into your terminal.

Edit files, search, check Git, and run your shell without switching apps. It follows your Ocean theme and font, with full Myanmar support while you type.

Overview

The editor is built into Ocean and follows your theme, font, and workspace. It opens in its own window by default; use edit --here to switch the current window instead.

  • Everything in one window: tabs, file explorer, command palette, search, and problems.
  • Helpful language tools: syntax highlighting, LSP completion, diagnostics, and hover.
  • Git built in: changes panel, gutter markers, diff view, and inline blame.
  • Myanmar-ready: cursor movement, selection, and deletion keep Burmese syllables intact.
  • Easy on the eyes: follows your Ocean theme, font, and editor font scale.

Launching the editor

There are two entry paths: launch it directly as an editor, or toggle it on top of a running terminal session.

Entry pointHow
ocean edit [PATH]Open a file or folder in a separate editor window. No path opens the current directory.
edit --here [PATH]Open the editor in the current Ocean window instead.
Ctrl+Shift+ISwitch between terminal and editor in the current window.
Ctrl+Shift+OOpen the current file or workspace in a separate editor window.
Ctrl+\Split the window: editor on top, terminal below.
Launch examples 
# Open a file in a separate editor window
ocean edit src/main.rs

# Open a folder as the workspace
ocean edit .

# Open in the current window instead
ocean edit --here .
Separate window by default. Use --here when you want the editor in the current window.

Workspace modes

The editor shares the window with the terminal in three layouts. Switching is instant and does not restart your shell or close open documents.

Mode A

Pure Terminal

The default Ocean view. Your editor documents stay open in the background.

Ctrl\to reopen Split
Mode B

Split

Editor on top and a live terminal below. Drag the divider to resize.

Ctrl\
Mode C

Pure Editor

The editor fills the window for focused work.

CtrlShiftI

The same modes are available from the command palette (Ctrl+P) under View: Pure Editor Viewport, View: Toggle Terminal Split, and View: Pure Terminal Mode.

Vim keybindings (opt-in)

Set editor-keymap = vim in ~/.config/ocean/config (it hot-reloads) to switch the editor to modal editing. The default remains modeless.

ModeEnterBehavior
NORMALEscMotions and operators, block cursor
INSERTi a I A o OTyping and IME/Myanmar input

Supports familiar motions, counts, operators, Visual selections, undo/redo, and :w / :q commands. Burmese syllables stay intact during deletion.

Interface

A simple, focused layout that stays the same in Split and Pure Editor modes.

  • Tabs and breadcrumbs show open files and the current path.
  • Activity bar: Explorer, Search, Problems, Plugins, and Git.
  • Git: branch and changed files, gutter markers, diff view, and inline blame.
  • Status bar: line/column, errors and warnings, language, and branch.
  • Clear dialogs: save or discard unsaved work before closing a file or the app.
  • Nerd Font icons with automatic PNG fallback.

File explorer

Toggle the workspace tree with Ctrl+B. The sidebar is backed by the folder you opened with ocean edit <dir> (or the inherited shell working directory).

  • Click a folder to expand it, or a file to open it.
  • Click the header to rescan the workspace.
  • Drag the right edge to resize the sidebar.

Command palette & file finder

Press Ctrl+P or Ctrl+Shift+P for a bottom : prompt that finds files and runs commands.

  • Type to filter files and actions.
  • Enter runs, Esc closes.

Syntax highlighting works out of the box. Install a language server for completion, hover, and diagnostics.

Servers start automatically when a supported file opens. If one is missing, editing still works and completion falls back to words already in the file.

Myanmar editing

Burmese syllables stay together while you type, move the cursor, select, and delete.

Everyday text
မင်္ဂလာပါ — မြန်မာဘာသာစကား
Stacked consonants
ပြည်ထောင်စု • ဗုဒ္ဓဘာသာ • ဣန္ဒြေ • တက္ကသိုလ်
  • Cursor movement and deletion work on complete syllables.
  • IBus, Fcitx, and Keyman input goes to the editor, not the shell.
  • Adjustable Myanmar font size and optional Zawgyi display.

Plugins

Optional sandboxed plugins can add commands and status items. Install one from a local file or URL: 

ocean +plugin-install plugin.wasm
ocean +plugin-list

Enable, disable, or remove plugins from the Plugins panel.

Customization

Workspace toggles are ordinary Ghostty-style keybinds, so they can be rebound in ~/.config/ocean/config. The editor itself uses your active theme palette and terminal font.

~/.config/ocean/config 
# Workspace toggles
keybind = ctrl+shift+i=toggle_editor
keybind = ctrl+backslash=toggle_split_mode

# Editor menu bar, keymap, and session recovery
window-show-menu-bar = true
editor-keymap        = modeless
restore-session     = true
crash-recovery      = true
autosave-interval   = 15

# Theme and typography are shared with the terminal
theme                = ocean-dark
font-family          = Cascadia Code NF
font-family-myanmar = Padauk
font-size            = 13.5
editor-font-scale   = 0.92
  • Changes apply live when you save the config.
  • Validate with ocean +validate-config or inspect with ocean +show-config.
